## Pre-requisites
These steps are meant to be completed from another PC.

Download all the files from https://images.cybermyth.dev/arm64/sp12/.

Once downloaded, dcompress the `.cybermyth-sp12-desktop.img.zst` image.
```bash
zstd -d cybermyth-sp12-desktop.img.zst
```
Check if the decompressed image is correct against `cybermyth-sp12-desktop.img.sha256`.
```bash
sha256sum cybermyth-sp12-desktop.img
7083dd20ab264fbed26856261ae30a58ed56c51765249da6ff116becb0166c3a  cybermyth-sp12-desktop.img
```
### Recommended
Use the installer provided by us to create a bootable drive (make sure all the checksums are present in the target directory).

**Important**: verify which device is your pendrive using `lsblk`. 
In our case it was `/dev/sdb`.

To create bootable drive:
```bash
sudo ~/Downloads/write-usb.sh ~/Downloads/cybermyth-sp12-desktop.img /dev/sdb
```

The bootable drive will be persistent and can be used directly too.


## Installation
**Read this before installing!**

The tablet does not support creation of Boot menu entry directly through Linux, we will have to use **Windows** `bcdedit` for it post installation (3 small commands).

### On Surface Pro 12
- From the start menu open `Create and format hard disk partitions`.
  - Right Click on `Local Disk C` -> Shrink Volume. Shrink atleast 100GBs (102400 MB). Do not format the shrunk space.

- To get into the firmware settings on the  SP12, `complete shutdown` -> `Hold Volume Up` -> `Tap Power Button` and wait till the UEFI firmware appears. 
  - Turn Off Secure Boot and in the Boot Order, drag the USB storage option to top.
  - Swipe the USB storage option to boot from it immediately.

- CyberMyth OS will boot from the pendrive automatically. Login using password:`cybermyth`.
  ![first](/ARM64/images/sp-12.png)
    - Open the `Disks` application, select the Format the shrunk space created from Windows (marked unallocated) as `Ext4`.
    - Finally open the CyberMyth Installer from the Dashboard and enter the password `cybermyth`.
- In the installer carefully choose the partition on the internal drive that you just formatted as `Ext4` and choose username, password and device name.
  ![installer](/ARM64/images/sp-12-1.png)

- Once the installation completes it will show the actual 3 commands that need to be typed in your Windows terminal and installation info.
  ![completion](/ARM64/images/sp-12-2.png)

You can close this and reboot into Windows.

## Boot Entry Creation

On windows on Surface Pro 12, open Terminal as Administrator.
- Use `diskpart` to `assign letter=X` to your System (ESP) partition.
- Then as Administrator, type:
  ```ps
  cd X:\
  cmd
  ```
  ```ps
  bcdedit /copy {bootmgr} /d "CyberMyth OS"
  ```
  This will output a **GUID** in the form `{3dd0.....}`. Copy it. (Please use your full copied GUID in the following commands, I am using this placeholder)
  ```ps
  bcdedit /set {3dd0...} path \EFI\cybermyth\BOOTAA64.EFI
  ```
  ```ps
  bcdedit /set {fwbootmgr} displayorder {3dd0...} /addlast
  ```

Now, you can safely power off, boot into UEFI firmware settings and boot `CyberMyth OS`.
