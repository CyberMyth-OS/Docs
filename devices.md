**Motive**: CyberMyth is a Debian-based operating system that aims to provide a fully customizable hacking OS with the anonymity of operating systems like Tails.

We also aim for better aesthetics ;)

**Note**: We provide the software and brings the tools together but how anonymous you are depends on your personal practices and expertise. The CyberMyth Anonymity tool (present within the Upstream releases) only routes all your traffic through the desired Proxy/VPN/Tor. Evading trackers (such as turning off firefox telemetry,captive portal detection, changing user agent, blocking trackers etc) is upto the you. If you plan to use Tor for anonymity use Tor Browser.

This page lists the devices supported by CyberMyth 1.0 and their current status.

- **Alpha**: Under testing by developer.
- **Beta**: Publicly released but does not include the `cybermyth-os` apt repository, which provides core anonymity tools and additional hacking tools.
- **Upstream**: Released and contains the CyberMyth repository with tested anonymity and hacking tools.
