## Pre-requisites
These steps are intended to be completed from another PC.

Download all the files from https://images.cybermyth.dev/arm64/sp12/.

Once downloaded, decompress the `.cybermyth-sp12-desktop.img.zst` image.
```bash
zstd -d cybermyth-sp12-desktop.img.zst
```
Check if the decompressed image is correct against `cybermyth-sp12-desktop.img.sha256`.
```bash
sha256sum cybermyth-sp12-desktop.img

7083dd20ab264fbed26856261ae30a58ed56c51765249da6ff116becb0166c3a  cybermyth-sp12-desktop.img
```
### Recommended
Use the installer provided by us to create a bootable drive. Ensure all the checksums are present in the target directory.

**Important**: Verify which device corresponds to your USB device using `lsblk`. 
In our case it was `/dev/sdb`.

To create bootable drive:
```bash
sudo ~/Downloads/write-usb.sh ~/Downloads/cybermyth-sp12-desktop.img /dev/sdb
```

This creates a persistent bootable drive with the credentials `cybermyth:cybermyth` and the **CyberMyth OS Installer**.


## Installation
**Read this before installing!**

The Surface Pro 12 does not support creating a Boot menu entry directly through Linux. We will therefore need to use **Windows** `bcdedit` to create the boot entry after installation. This requires 3 small commands.

### On Surface Pro 12
- From the start menu open **Create and format hard disk partitions**.
  - Right Click on `Local Disk (C:)` -> Shrink Volume. Shrink atleast 100GBs (102400 MB). **Do not format the newly created unallocated space**.

- To access the firmware settings on the  Surface Pro 12,  perform a **complete shutdown** -> **Hold Volume Up** -> **Tap the Power Button** and wait for the UEFI firmware screen to appear.
  - Turn Off Secure Boot and, under the **Boot Order Settings**, drag the USB storage option to top.
  - Swipe the USB storage option to boot from it immediately.

- CyberMyth OS will boot automatically from the USB drive. Login using the password:`cybermyth`.
  ![first](/ARM64/images/sp-12.png)
    - Open the `Disks` application, select the select the unallocated space created in Windows prevously, and format it as `Ext4`.
    - Finally, open the CyberMyth Installer from the Dashboard and enter the password `cybermyth`.
- In the installer, carefully select the partition on the internal drive that you just formatted as `Ext4`. Then choose username, password, and device name.
  ![installer](/ARM64/images/sp-12-1.png)

- Once the installation is complete, the installer will display the 3 commands that need to be entereed in the Windows terminal, along with the installation information.
  ![completion](/ARM64/images/sp-12-2.png)

You can close the installer and reboot into Windows.

## Boot Entry Creation

On Windows, on the Surface Pro 12, open Terminal as **Administrator**.
- Use `diskpart` to `assign letter=X` to your **System (ESP) partition**.
- Then, as Administrator, enter the following:
  ```ps
  cd X:\
  cmd
  ```
  ```ps
  bcdedit /copy {bootmgr} /d "CyberMyth OS"
  ```
  This will output a **GUID** in the form `{3dd0.....}`. Copy the entire GUID. (For the following commands `{3dd0..}` is used as the laceholder.)
  ```ps
  bcdedit /set {3dd0...} path \EFI\cybermyth\BOOTAA64.EFI
  ```
  ```ps
  bcdedit /set {fwbootmgr} displayorder {3dd0...} /addlast
  ```

Now, you can safely power off the device, boot into the **UEFI firmware settings** and select the `CyberMyth OS` entry.
