### Pre-requisites
Download the `.zst` image from [Image Archive](https://images.cybermyth.dev/arm64/sp12/cybermyth-1.0).

Once downloaded, decompress the `.cybermyth-sp12-desktop.img.zst` image.
```bash
zstd -d cybermyth-sp12-desktop.img.zst
```
Check if the decompressed image is correct against `cybermyth-sp12-desktop.img.sha256`.
```bash
sha256sum cybermyth-sp12-desktop.img
```

## Feature Reference

### Platform

| Item | Value |
|---|---|
| Base | Debian 13 trixie, arm64 |
| SoC | Qualcomm X1P42100 (Purwa platform, `purwa.dtsi` on `hamoa.dtsi`) |
| Kernel | `7.2.3-cybermyth-sp12` |
| Device tree | `x1p42100-microsoft-sp12in.dtb` |
| Bootloader | GRUB standalone, `/EFI/cybermyth/BOOTAA64.EFI` |
| Boot entry creation | automatic, `efibootmgr`|
| Init | systemd |

### CPU

| Item | Value |
|---|---|
| Topology | 8 Oryon cores, 2 clusters (`policy0` cpu0-3, `policy4` cpu4-7) |
| Frequency driver | `scmi` |
| Frequency range | 710400 – 3244800 kHz, 12 OPPs, both clusters identical |
| Default governor | `schedutil` (kernel config default) |
| Available governors | schedutil, ondemand, conservative, powersave, performance, userspace |
| EPP | unavailable (scmi driver) |
| Boost | disabled |
| Energy Aware Scheduling | unavailable — cores are symmetric, no `capacity-dmips-mhz` |
| CPU idle | `WFI` + `cpu-sleep-0`; cluster power-collapse `cluster_c4` |

### Power management

| Item | Value |
|---|---|
| Profile daemon | power-profiles-daemon, `PlatformDriver: placeholder` (inert) |
| Profiles | `balanced`, `power-saver` |
| Policy agent | `cybermyth-powersave.service` (package `cybermyth-sp12`) |
| Governor policy | `schedutil` applied in both profiles |
| Frequency cap, power-saver | `scaling_max_freq` 2188800 kHz |
| Frequency cap, balanced | `cpuinfo_max_freq` 3244800 kHz |
| Sensor stack, power-saver | `hexagonrpc` and `iio-sensor-proxy` stopped |
| Sensor stack, balanced | started |
| Suspend hook | `iio-sensor-proxy-suspend.service`, armed in balanced, disarmed in power-saver |
| Suspend sensor teardown | stops proxy then bridge before `sleep.target`, restores on resume |
| PMIC wakeup sources | disabled via `/etc/tmpfiles.d/disable-pmic-wakeup.conf` (ac, bat, usb, wls) |
| ADSP handover IRQ storm | fixed by mainline `bb7c5d6f5b41`, backported (absent from 7.2.x) |

### Storage and installation

| Item | Value |
|---|---|
| Installer | Calamares 3.3.14 |
| Root filesystem | ext4 (the only filesystem offered) |
| Encryption | disabled — `enableLuksAutomatedPartitioning: false`, `luksbootkeyfile` omitted from the sequence |
| Partitioning | manual pre-selected; Calamares also offers erase / replace / alongside |
| Copy method | `unpackfs` rsync from a bind mount of `/`, not a squashfs |
| Bootloader build | `grub-mkstandalone`, menuless, embedded config carrying the `devicetree` line |
| ESP handling | existing ESP reused, never formatted; one file added, `/EFI/cybermyth/BOOTAA64.EFI` |
| Boot entry | `efibootmgr`, placed first in `BootOrder`; existing entries listed, never deleted |
| Windows protection | `/EFI/Microsoft` and `/EFI/BOOT` never read or written; Windows' own boot entry left in place |
| fstab | root only; the shared ESP is left unmounted at runtime |
| machine-id | regenerated per install (`machineid` module) |
| First boot | root filesystem expanded to device size, once |
| Swap | zram via `zram-tools` |
